### 산출물
**산출물 › 산출물**에서 사업 단계별 산출물을 관리합니다. 처음에는 **[표준 목록으로 시작]**을 누르면 공공 SI 표준 산출물 34종이 만들어집니다.

| 단계 | 예 |
|---|---|
| 착수 | 사업수행계획서 · 방법론 조정 결과 |
| 분석 | 요구사항 정의서 · 요구사항 추적표 · 현행 분석서 |
| 설계 | 화면 설계서 · 메뉴 구조도 · 테이블 정의서 · ERD · 인터페이스 정의서 |
| 구현 | 프로그램 목록 · 소스코드 · 단위 테스트 결과서 |
| 시험 | 통합 · 인수 테스트 시나리오와 결과서 · 결함 조치 내역 |
| 이행 · 종료 | 데이터 이관 결과 · 사용자 매뉴얼 · 완료보고서 |

#### 작성 · 검토 · 승인
**미작성 → 작성 중 → 검토 → 승인 → 제출**

1. 담당자가 파일을 올립니다 — 올릴 때마다 버전이 쌓이고 최신본이 표시됩니다
2. **[검토 요청]** → 승인 권한자(PM/PL)가 **승인** 또는 **반려**(이유 필수)
3. 승인된 산출물을 발주처에 내면 **[제출]**. 고칠 일이 생기면 **되돌림**
4. 처리자 · 일시 · 의견 · 버전이 이력으로 남습니다

#### 자동 생성
WBS · ERD · 테이블 정의서 · 요구사항 정의서 · 추적표 · 화면 설계서(PPT) · 프로그램 목록 · 테스트 결과서 · 결함 조치 내역 · 인터페이스 정의서 · 배치 정의서 · 용어사전 · 감리 시정조치 · 투입 인력 · 보안약점 진단 등은 **[최신본 받기]**를 누를 때마다 **지금 데이터로** 만들어집니다. 따로 엑셀을 고칠 필요가 없습니다.

#### 검수용 일괄 다운로드
**[검수용 일괄 다운로드]** — 단계 폴더(`02_분석/A-01_…`)별로 최신 파일 + 자동 생성 문서 + `산출물목록.xlsx`(승인자·승인일시, 검토·승인 이력)를 zip 하나로 받습니다.

### 보고서
**산출물 › 보고서**에서 이번 주 · 지난주 · 이번 달 · 지난달 · 직접 기간을 고르면 주간 · 월간 보고 내용을 미리 보고 엑셀로 받습니다.

- 일감 실적(완료 · 진행) · 다음 기간 계획 · 기한 지남 · 버전 진척 · 이슈·위험 · 변경요청 · SR 처리 · 테스트 · 산출물 현황
- 프로젝트 **개요**의 종합 대시보드(요구사항 · 프로그램 · 테스트 · 위험 · 산출물 · 변경요청 · 일감 · SR · 감리)와 함께 쓰면 주간 회의 자료가 됩니다

### 회의록
1. **새 회의록**: 일시 · 장소 · 참석자(구성원 추가 또는 외부 인원) · 안건 · 내용 · 결정 사항
2. **후속 조치**에 할 일 · 담당 · 기한을 적으면 일감이 자동으로 만들어집니다
3. **인쇄**로 서명용 회의록을 출력합니다

### 이슈 · 위험
- **위험**(앞으로 생길 수 있는 문제)과 **이슈**(이미 생긴 문제)를 R-001 번호로 관리합니다
- **가능성 × 영향**으로 등급(상 · 중 · 하)이 정해지고 **위험 매트릭스**에 표시됩니다
- 상태: 식별 → 대응 중 → 관찰 → 종료 / 발생. 대응 계획과 담당 · 기한, 관련 일감을 적습니다
- 등급 **상**인 열린 위험이 있으면 프로젝트 현황이 **위험**으로 표시됩니다. 관리대장은 엑셀로 받습니다

### 감리
1. **감리 회차**를 만듭니다 — 단계(요구정의 · 설계 · 종료) · 기간 · 감리 기관
2. 지적사항을 등록하거나 엑셀로 가져옵니다 — AU-001 · 영역 · 구분(시정 · 권고 · 참고) · 근거 산출물
3. 조치 계획 · 담당 · 기한 → 조치 결과 · 조치일 → 감리인 확인
4. **시정조치 계획서 · 결과서** 엑셀을 받아 감리 기관에 제출합니다

### 투입 인력
보기 권한이 따로 있습니다 (기본 PM/PL).

- 이름(Redmine 사용자 연결 또는 외부 인원) · 소속 · 역할 · 등급 · 투입 기간 · **투입률**
- **계획 M/M** = 투입 기간(월별 날짜 비율) × 투입률, **실적 M/M** = 이 프로젝트 소요시간 ÷ 168시간 (사용자를 연결한 인력만)
- **월별 계획 대 실적** 표: 달마다 계획 · 실적 · 차이 · 실적률. 실적이 계획보다 많이 적으면 소요시간 기록이 빠진 것은 아닌지 확인하세요
- **보안 서약서** 제출일 · 발급 계정 · **계정 회수일** — 철수했는데 회수일이 없으면 빨간색으로 표시됩니다
- 인력 교체는 교체 전 인력 · 사유 · 승인일을 남깁니다. 투입인력 현황 엑셀(월별 계획 · 실적 시트 포함)

### 준공 체크리스트
