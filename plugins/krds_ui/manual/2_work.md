### 일감 등록
**일감 › 새 일감**에서 유형·제목·설명·담당자·시작일·완료 기한을 적습니다. 화면과 관련된 일감은 **메뉴**를 고르면 메뉴 구조도와 연결됩니다.

| 유형 | 쓰는 경우 |
|---|---|
| 기능 | 신규 화면·기능 개발 |
| 결함 | 테스트에서 나온 결함 (테스트 결과 화면에서 자동으로 만들 수 있음) |
| 오류 | 화면상 오류 — 시스템 영향은 없는 작은 오류 |
| 지원 | 문의 대응·자료 지원 |
| 작업 | 그 밖의 일반 작업 (WBS) |
| 테스트 | 테스트 수행 작업 |
| 데이터 이관 | DB 및 데이터 이관 작업 |
| 회의 | 회의 일정 |
| 시안 수정 · 퍼블리싱 | 디자인 시안 수정, 화면 퍼블리싱 |
| SR | 유지관리 서비스 요청 (아래 SR 참고) |

- **상위 일감**을 지정하면 WBS 처럼 트리로 묶이고, 상위 일감의 일정·진척은 하위 일감으로 계산됩니다
- 설명에는 재현 절차·기대 결과·화면 캡처를 붙여 주세요 (붙여넣기로 이미지 첨부 가능)

### 상태 흐름
| 상태 | 뜻 | 누가 |
|---|---|---|
| 신규 | 등록됨, 아직 시작 전 | |
| 진행 | 작업 중 | 담당자 |
| 해결 | 작업 끝, 확인 요청 | 담당자 |
| 의견 | 질문·추가 정보 필요 | 누구나 |
| 보류 | 잠시 멈춤 (열린 상태) | 담당자 |
| 완료 | 확인 끝, 닫힘 | **PM/PL** |
| 거절 | 하지 않기로 함, 닫힘 | **PM/PL** |

> 작업자는 **해결**까지, PM/PL 이 확인 후 **완료**로 닫습니다. 커밋 메시지에 `fixes #번호` 를 쓰면 자동으로 해결 상태가 됩니다 (개발 탭 참고).

### 일감 목록 활용
- **검색조건**: 상태·유형·담당자·메뉴 등으로 거르고 **저장**하면 사이드바에 내 검색으로 남습니다
- **열 선택**: 옵션에서 메뉴·진척도·완료 기한 등 보이는 열을 바꿉니다
- 여러 일감을 체크하고 오른쪽 클릭하면 상태·담당자·완료 기한을 한 번에 바꿉니다
- **CSV·PDF** 내보내기는 목록 아래에 있습니다

### 소요시간
- 일감 화면의 **소요시간 기록** 또는 커밋 메시지의 `@1h30m` 으로 기록합니다
- 작업분류: 설계 · 개발 · 수정. 투입 인력의 **실적 M/M** 은 이 소요시간으로 계산됩니다 (168시간 = 1 M/M)

### SR — 유지관리 서비스 요청
유지관리 프로젝트는 **설정 › 일감 유형**에서 SR 을 켭니다. 발주처 역할은 SR 만 등록할 수 있습니다.

| 항목 | 내용 |
|---|---|
| 요청 구분 | 장애 · 변경 · 개선 · 문의 · 자료 요청 |
| 긴급도 (필수) | 긴급 · 높음 · 보통 · 낮음 |
| 요청자 | 요청한 사람 (발주처 담당자 등) |

**처리 기한**: 완료 기한을 비워 두고 저장하면 긴급도로 자동 계산됩니다 (영업일, 주말 제외, 시작일 기준)

| 긴급도 | 긴급 | 높음 | 보통 | 낮음 |
|---|---|---|---|---|
| 기한 | 당일 | 1일 | 3일 | 5일 |

- **SLA 준수율** = 기한 안에 닫힌 SR 비율 — 프로젝트 개요 대시보드와 월간 보고서에 나옵니다
- SR 기한이 지나면 프로젝트 현황 신호등이 **위험**이 됩니다

### 간트 차트 · 달력 · 로드맵
- **간트 차트**: 시작일·완료 기한이 있는 일감을 막대로 보여 줍니다. 상위 일감·버전별로 묶이고 PDF·PNG 로 받을 수 있습니다
- **달력**: 시작·완료 일정을 월별로 봅니다
- **로드맵**: 버전(차수·마일스톤)별 진척. 일감의 **목표 버전**을 지정하면 나옵니다

### 일정 기준선
계획 대비 얼마나 늦어졌는지 보려면 **기준선**을 저장해 둡니다. (모듈 "일정 기준선")

1. 착수 계획이 확정되면 **일감 › 일정 기준선**에서 이름(예: 착수 계획)을 적고 **[지금 일정으로 기준선 저장]**
2. 변경요청이 승인되어 일정이 바뀌면 새 기준선(예: 1차 변경 승인)을 또 저장합니다
3. 기준선을 고르면 지금 일정과 비교합니다 — **종료일 변동**, 늦어진·앞당겨진·추가된·삭제된 일감, 일감별 완료 기한 변동(일)과 진척
4. **[비교 엑셀]**로 보고 자료를 받습니다

> 프로젝트 현황(PMO)은 **가장 최근 기준선** 대비 종료일이 7일 이상 늦으면 주의, 30일 이상이면 위험으로 표시합니다.
