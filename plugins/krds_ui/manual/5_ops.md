### 자산
**운영 › 자산**에 서버 · 도메인 · SSL 인증서 · 라이선스 · 클라우드 · 장비를 등록합니다.

- 항목: 구분 · 주소 · 사양 · 공급사 · 담당 · **만료일** · 갱신 주기 · 연결된 DB 서버 / Jenkins 서버
- 여러 프로젝트가 함께 쓰는 자산은 관리자가 **관리 › 자산 대장**에 공용 자산으로 등록하고 프로젝트에 연결합니다
- 목록 위 KPI: **만료됨 · 7일 이내 · 30일 이내**. 만료 30·7·1일 전 · 당일 · 다음 날에 담당자에게 메일로 알립니다
- 계정·비밀번호는 자산에 적지 말고 **접속정보(Vault)**에 등록하세요

### 스케줄러 (배치)
**운영 › 스케줄러**에 cron · Spring @Scheduled · Quartz · Windows 작업 스케줄러 · Jenkins · DB 잡을 한곳에 모읍니다.

- 일정을 입력하면 바로 **한국어 풀이**("평일 02:00", "09~18시 30분마다")와 **다음 실행 시각**을 보여 줍니다
- **24시간 타임라인**: 시간대별 실행 수, 가장 몰린 시간, 같은 서버에서 실행 시간이 겹치는 작업을 표시합니다
- **가져오기**
  - 서버에서 `crontab -l` 결과를 붙여넣기 (시스템 crontab 형식도 선택 가능)
  - DB 잡: DB 관리가 읽은 이벤트 · pg_cron · Oracle 스케줄러 · SQL Server 에이전트
  - Jenkins 배포 대상의 빌드 주기 · SCM 폴링
  - 같은 항목은 다시 가져와도 한 번만 들어갑니다
- 실행 계정 · 예상 소요 · 선후행 작업 · 실패 시 대응 · 관련 테이블을 적고 **배치 정의서** 엑셀로 받습니다

### 점검 · 장애
**운영 › 점검·장애**에서 장애 기록과 정기점검을 관리합니다.

#### 장애
1. 등급 · 발생 / 인지 / 복구 시각을 적으면 **중단 시간**이 자동 계산됩니다
2. 영향 범위 · 원인 · 조치 · 재발 방지 대책을 기록합니다
3. 후속 작업은 **일감 만들기**로 연결합니다

#### 정기점검
1. **점검표 양식**을 만들어 둡니다 (예: 월간 서버 점검 — 디스크, 백업, 로그, 인증서)
2. 점검할 때 양식을 골라 항목별로 정상 · 이상 · 해당 없음을 기록합니다

#### 월간 보고서
엑셀 한 파일에 요약 · 장애 · 정기점검 · 일감 처리 · 배포 이력 · DB 구조 변경 · 만료 예정 자산이 들어갑니다. 유지관리 월간 보고 자료로 씁니다.

### 인터페이스
**운영 › 인터페이스**에 외부·내부 시스템과의 연계를 정의합니다.

| 항목 | 예 |
|---|---|
| ID | IF-001 (자동) |
| 방향 · 상대 시스템 | 송신 / 수신 / 양방향 · 행정정보 공동이용 |
| 방식 | REST · SOAP · DB 링크 · SFTP · MQ · 배치 |
| 주기 | 실시간 또는 스케줄러의 작업 연결 |
| 데이터 · 관련 테이블 | 주고받는 항목, 읽고 쓰는 테이블 |
| 주소 · 담당 | 개발 / 운영 주소, 양쪽 담당자 |

- **구성도**: 인터페이스를 그림으로 보고 SVG · PNG · `.md` · draw.io 로 받습니다
- **인터페이스 정의서** 엑셀

### 접속정보 (Vault)
서버 · DB · 관리자 계정 같은 민감한 접속 정보는 **접속정보(Vault)**에 암호화해 보관합니다.

1. 프로젝트 **운영 › 접속정보** 또는 상단 **접속정보**에서 **새 접속정보**
2. 유형(서버·DB·웹 관리자 등) · 이름 · 주소 · 계정 · 비밀번호 · 메모를 적습니다. 파일(키 파일 등)도 암호화되어 저장됩니다
3. 목록에서 비밀번호는 가려져 있고 **복사** 버튼으로 바로 복사합니다
4. 볼 수 있는 사람은 역할과 화이트리스트로 정합니다

> **보안 수칙** — 접속정보를 메신저 · 메일 · 위키 · 일감 본문에 적지 마세요. 인력이 철수하면 그 사람이 알던 계정의 비밀번호를 바꾸고 투입 인력의 **계정 회수일**을 기록합니다.

### 백업 (관리자)
- PMS 는 매일 DB · 첨부파일 · 키 파일을 서버 안에 날짜별로 백업하고 14일 동안 보관합니다
- **관리 › 백업**에서 최근 백업 상태 확인과 **[지금 백업]**을 할 수 있습니다. 복원은 서버 관리자가 복원 스크립트로 합니다
