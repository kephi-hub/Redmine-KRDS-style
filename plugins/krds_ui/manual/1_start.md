### PMS 한눈에 보기
PMS 는 공공 SI·유지관리 사업의 **일정·일감 · 설계 · 개발 · 운영 · 산출물**을 한곳에서 관리하는 프로젝트 관리 시스템입니다. 요구사항부터 메뉴(화면), 프로그램, 테스트, 결함, 산출물까지 서로 연결되어 있어 한 곳을 고치면 추적표·대시보드·보고서에 바로 반영됩니다.

흐름: **요구사항 → 메뉴(화면) → 프로그램(기능) → 일감 → 테스트 → 결함 → 산출물 → 준공**

### 화면 구성
#### 상단 공통 메뉴
| 메뉴 | 하는 일 |
|---|---|
| 초기화면 | 지금 보고 있는 화면 — 공지와 사용 매뉴얼 |
| 내 페이지 | 내가 맡은 일감 · 보고한 일감 등 나만의 대시보드 (오른쪽 위 [추가]로 블록 추가) |
| 프로젝트 | 내가 구성원인 프로젝트 목록 |
| 프로젝트 현황 | 볼 수 있는 진행 중 프로젝트를 신호등으로 한 화면에서 비교 (PMO) |
| 접속정보 | 서버·DB·계정 정보를 암호화해 보관하는 Vault |
| 도움말 | Redmine 공식 도움말 |

#### 프로젝트 메뉴 — 대분류 7개
프로젝트에 들어가면 위쪽에 대분류가 보이고, 누르면 아래로 세부 메뉴가 펼쳐집니다. 모바일에서는 오른쪽 위 ☰ 를 누르면 전체 화면 메뉴가 열립니다.

| 대분류 | 세부 메뉴 |
|---|---|
| 개요 | 개요(종합 대시보드) · 작업내역 |
| 일감 | 일감 · 새 일감 · 간트 차트 · 달력 · 로드맵 · 일정 기준선 · 소요시간 |
| 설계 | 요구사항(변경요청 탭 포함) · 메뉴 구조도(화면 캡처 탭 포함) · 시스템 권한 · 용어사전 |
| 개발 | 저장소 · 프로그램 목록 · DB · 테스트 · 보안약점 · 배포 |
| 운영 | 자산 · 스케줄러 · 점검·장애 · 인터페이스 · 접속정보 |
| 산출물 | 산출물 · 보고서 · 준공 체크리스트 · 회의록 · 이슈·위험 · 감리 · 투입 인력 · 문서 · 파일 |
| 협업 | 위키 · 게시판 · 뉴스 |

> 메뉴가 보이지 않으면 그 기능(모듈)이 꺼져 있거나 권한이 없는 것입니다. 프로젝트 **설정 › 모듈**에서 켜거나 PM/PL 에게 요청하세요.

### 내 계정
- 오른쪽 위 **내 계정**에서 이름·메일·알림 방법·시간대를 바꿉니다. 비밀번호는 **비밀번호 변경**에서 바꿉니다
- **2단계 인증**(인증 앱)을 켜 두는 것을 권장합니다 — 내 계정 › 2단계 인증 사용
- 메일 알림 기본값은 "내가 맡거나 작성한 것만"입니다. 관심 있는 일감은 일감 화면의 **지켜보기**를 누르면 변경 알림을 받습니다

### 역할과 권한
프로젝트마다 구성원에게 역할을 줍니다. 같은 사람도 프로젝트마다 역할이 다를 수 있습니다.

| 역할 | 할 수 있는 일 |
|---|---|
| **PM/PL** | 모든 기능 · 일감 완료/거절 · 요구사항·변경요청 승인 · 산출물 승인 · 기준선·준공 관리 · 투입 인력 · 캡처 설정 |
| **개발자** | 일감 처리 · 프로그램 · 테스트 케이스·결과 · DB 조회(개발) · 메뉴 구조도 편집 · 배포 실행 |
| **디자이너** | 일감 처리 · 메뉴 구조도 편집 · 테스트 결과 입력 (업무흐름·접속정보 범위가 개발자와 다름) |
| **조회자** | 대부분의 화면 보기만 |
| **발주처** | 진척·산출물·보고서·요구사항·테스트·감리·화면 캡처 보기 + **SR 등록·댓글**만 (투입 인력·접속정보·DB·소요시간은 보이지 않음) |

- 프로젝트는 기본으로 **비공개**라 구성원만 볼 수 있습니다. 프로젝트 만들기·삭제·공개 전환은 관리자만 합니다
- 일감 **완료·거절**은 PM/PL 만, **보류**는 작업자도 고를 수 있습니다

### 새 프로젝트 시작 순서
1. **관리자**가 프로젝트를 만들고 PM/PL 을 구성원으로 넣습니다
2. **설정 › 모듈**에서 쓸 기능을 켭니다 (모듈 화면도 대분류 카드로 묶여 있습니다)
3. **설정 › 구성원**에 팀원을 역할과 함께 추가합니다. 발주처 담당자는 **발주처** 역할로
4. **산출물 › 산출물 › [표준 목록으로 시작]** — 공공 SI 표준 산출물 34종이 단계별로 만들어집니다
5. **설계 › 요구사항**을 등록하거나 엑셀로 가져옵니다
6. **설계 › 메뉴 구조도**에 화면을 정리하고, **개발 › 프로그램 목록**을 메뉴에서 만듭니다
7. 일감(WBS)을 등록하고 계획이 확정되면 **일감 › 일정 기준선**에 "착수 계획"으로 저장합니다
8. **산출물 › 투입 인력**에 인력과 투입 기간·투입률을 등록합니다

### 프로젝트 현황 (PMO)
상단 **프로젝트 현황**은 내가 볼 수 있는 진행 중 프로젝트를 한 줄씩 비교합니다.

| 신호 | 기준 (하나라도 해당하면) |
|---|---|
| 🔴 위험 | 진척이 경과보다 20%p 이상 늦음 · 위험 등급 상 · 기한 지난 일감 5건 이상 · SR 기한 지남 · 산출물 마감 지남 3건 이상 · 기준선보다 종료 30일 이상 늦음 |
| 🟡 주의 | 진척이 경과보다 10%p 이상 늦음 · 기한 지난 일감 · 산출물 마감 지남 · 미조치 결함 · 감리 조치 기한 지남 · 기준선보다 종료 7일 이상 늦음 |
| 🟢 정상 | 위에 해당 없음 |

- **진척(막대) 대비 경과(세로선)**: 막대가 세로선보다 짧으면 계획보다 늦은 것입니다
- 권한이 없는 칸은 `-` 로 보입니다. 신호 필터·이름 검색·엑셀 받기가 있습니다

### 화면 사용 팁
- 알림·확인창은 화면 가운데 KRDS 모달로 뜹니다. **Esc** 로 닫을 수 있습니다
- 목록의 **검색조건**은 접어 둘 수 있고, 적용 중인 조건 개수가 표시됩니다. 자주 쓰는 조건은 **저장**해 두세요
- 표 위 **…(더보기)** 에 내보내기 등 추가 기능이 있습니다
- 본문(위키·일감·문서)에 ` ```mermaid ` 블록을 쓰면 그림으로 보이고, `{{term(용어)}}` 를 쓰면 용어사전 정의가 툴팁으로 나옵니다
